### A. 가격 텍스트 로케이터가 "숨겨진 모바일 중복 요소"를 먼저 집는 테스트 버그 (4건)

- `tests/e2e/subscribe.spec.ts:49` — `각 플랜 카드에 원가 및 할인가 표시`
- `tests/e2e/error-boundaries.spec.ts:211` — `구독 플랜 06 - 정상 상태`
- `tests/e2e/error-boundaries.spec.ts:219` — `구독 플랜 07 - 플랜 API 실패`

**원인**: `widgets/package-plans/ui/PlanPicker.tsx`가 같은 가격 텍스트(예: "39,000원")를 3곳에 중복 렌더링한다 — 모바일 전용 블록(DOM에서 제일 먼저 나오지만 데스크탑 뷰포트에서 `display:none`), 태블릿 전용 블록, 데스크탑 카드 목록(실제 보이는 곳). 기본 선택 플랜이 "베이직"(39,000원)이라 모바일 블록도 같은 텍스트를 갖게 되는데, 테스트가 `getByText("39,000원").first()`로 찾다 보니 **DOM 순서상 먼저인 숨겨진 모바일 블록을 집어서 "hidden"으로 실패**한다. 화면 자체는 정상 — 스크린샷 대조로 확인됨.

**고치려면**: 로케이터를 `page.locator("button").filter({ hasText: plan.name })` 안으로 스코프하거나, 데스크탑 카드 컬럼(`ref={cardColumnRef}`) 안으로 한정. (`subscribe.spec.ts`의 다른 테스트 "제품 상세보기" 클릭 케이스는 이미 버튼으로 스코프해서 안 걸림 — 같은 패턴 적용하면 됨.)
