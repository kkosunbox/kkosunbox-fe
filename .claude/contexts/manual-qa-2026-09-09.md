## 0. 상태 조합 시나리오

### 시나리오 0-1 — 배지 2종 동시 노출 시 태블릿 카드 폭

**왜 위험한가**: 기존엔 무료배송 배지가 카드 **이미지 위 오버레이**였어서 텍스트 줄과 폭을 다툴 일이 없었다(`PlanPicker.tsx`의 `FreeShippingBadge variant="image"` 오버레이). 이번 `ae2f9b0`에서 오버레이를 없애고 "인기 PICK"(`w-[86px]`) 배지 옆에 무료배송 배지(`withIcon={false}`, `w-[58px]`)를 `gap-2`(8px)로 나란히 붙였는데, 태블릿 카드 컨테이너 폭이 `w-[160px]` 고정이라 `86+58+8=152px` — 여유가 8px뿐이다. **오늘 처음 생긴 조합**(이전엔 두 배지가 겹칠 지점 자체가 없었음).
- [ ] 0-1-1. "인기 PICK 🌟" + "무료배송" 두 배지가 줄바꿈 없이 한 줄에 들어가는지
- [ ] 0-1-2. 브라우저 창 최대화 상태에서 폭 1024px·1199px 두 지점 모두 확인 (경계값)

**재현**: `/purchase` → 상품 카드 클릭 → `/purchase/detail` → 결제 진행 → `/purchase/order`
**왜 위험한가**: `purchaseOrderHelpers.ts`의 `computePurchaseTotals`에서 `basePrice >= PURCHASE_FREE_SHIPPING_THRESHOLD ? 0 : PURCHASE_SHIPPING_FEE` 분기가 삭제되고 `originalShippingFee = PURCHASE_SHIPPING_FEE`로 고정됐다 — **금액과 무관하게 항상 무료배송**이 된다. 커밋 메시지에 의도된 변경이라 적혀 있지만, 실제 판매 중인 티어(`CURRENT_PURCHASE_TIER = "Premium"`)의 가격이 3만원 미만으로 낮아지는 경우가 생기면 배송비 무료 문구가 늘 붙는다는 점을 실제로 보고 확정할 것.
