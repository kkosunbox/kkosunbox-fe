# 구독몰 리디자인 참고자료

구독몰 리디자인·리팩토링을 위한 원본 참고자료입니다.

- `subscription-selection-reference.png`: 사용자가 첨부한 PC 랜딩 페이지 시안 (원본 1920 × 1942)
- `subscription-selection-reference.css`: 사용자가 첨부한 디자인 도구의 CSS 원문

## 작업 메모

- 기준 브랜치: `origin/dev`
- 작업 브랜치: `codex/subscription-mall-redesign`
- 2026-09-28: 참고자료 보존 및 작업 브랜치 준비.
- CSS에는 디자인 도구가 내보낸 절대 좌표와 개별 요소 스타일이 포함되어 있으므로, 구현 시 그대로 적용하기보다 기존 디자인 토큰과 반응형 규칙에 맞춰 해석합니다.

## 2026-09-29 구현

- `/subscribe`: 흰색 헤더, 구독 안내 배너, 제목, 패키지 쇼케이스, 3종 선택 카드, 간식 구성 비교표.
- 메인 페이지의 쇼케이스를 `widgets/package-plans` 공용 위젯으로 추출하고 이미지도 함께 이동.
- 가격·할인율·평점은 기존 API와 `planDisplayPrice`를 사용. 시안의 예시 금액은 하드코딩하지 않음.
- 기본 스탠다드 선택, `?tier=` 초기 선택 우선, 카드 선택에 따른 이미지·가격·상세 링크 갱신.
- 기존 체크리스트 추천 모달과 조회·상세 이동 분석 이벤트 유지.
- 비교표 구성은 시안 기준으로 `entities/package/lib/packageComparison.ts`에서 관리.
- PC는 최대 1240px 콘텐츠, 태블릿은 3열 카드, 모바일은 세로 카드 및 비교표 내부 가로 스크롤.

## 검증

- TypeScript 및 전체 ESLint 통과 (설치된 실행 파일 직접 사용).
- 가격·추천 플랜 단위 테스트 13개 통과.
- 로컬 개발 서버에서 320, 360, 390, 768, 1024, 1200, 1440, 1920px 화면 검증.
- 구독 E2E 명세를 새 상세 링크와 선택 방식으로 갱신.
- 프로덕션 빌드 통과. 전체 E2E는 첫 홈 CTA 테스트가 이전 버튼 문구를 찾아 실패했고, 나머지 216개는 미실행.
- 리디자인 진행 중인 현 상황을 고려해 사용자가 E2E를 이번 커밋의 차단 조건에서 제외하도록 승인.
- computer-use로 현재 구독몰의 쇼케이스·카드·비교표를 직접 확인하고 패키지 전환 시 가격·상세 링크 변경을 확인. 큰 시각적 문제 없음.
- 브라우저 검증 캡처와 실행 결과는 로컬 `reports/subscription-redesign/`에 보관 (Git 제외).
