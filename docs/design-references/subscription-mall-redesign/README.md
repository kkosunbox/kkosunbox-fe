# 구독몰 리디자인 참고자료

내일 진행할 구독몰 리디자인·리팩토링을 위한 원본 참고자료입니다.

- `subscription-selection-reference.png`: 사용자가 첨부한 PC 랜딩 페이지 시안 (원본 1920 × 1942)
- `subscription-selection-reference.css`: 사용자가 첨부한 디자인 도구의 CSS 원문

## 작업 메모

- 기준 브랜치: `origin/dev`
- 작업 브랜치: `codex/subscription-mall-redesign`
- 현재는 참고자료만 보존했으며, UI 구현이나 리팩토링은 시작하지 않았습니다.
- CSS에는 디자인 도구가 내보낸 절대 좌표와 개별 요소 스타일이 포함되어 있으므로, 구현 시 그대로 적용하기보다 기존 디자인 토큰과 반응형 규칙에 맞춰 해석합니다.
